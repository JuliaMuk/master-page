СБОРЩИК СТРАНИЦ — HTML + CSS

Что это
Статическое веб-приложение: пользователи выбирают один из трёх шаблонов, редактируют HTML и CSS, видят предпросмотр и скачивают результат как отдельный HTML-файл.

Публикация на виртуальном хостинге
1. Распакуйте архив.
2. Загрузите файл index.html в корневую папку сайта на хостинге (часто это public_html, www или htdocs).
3. Откройте адрес сайта в браузере. Серверная часть, база данных, Node.js и сборка не нужны.

Локальный запуск
Откройте index.html в современном браузере. Для локальной разработки можно открыть папку в VS Code и использовать расширение Live Server, но это необязательно.

Возможности
- 3 готовых шаблона: афиша события, портфолио, кафе.
- Редактирование HTML и CSS с автоматическим предпросмотром.
- Режимы предпросмотра для компьютера и телефона.
- Автосохранение изменений в localStorage браузера пользователя.
- Сброс изменений и скачивание готовой страницы в одном HTML-файле.
- Встроенный iframe предпросмотра запускается в sandbox без выполнения пользовательских скриптов.

Важно
- Изменения сохраняются только в браузере пользователя и не передаются владельцу сайта или другим посетителям.
- Чтобы шаблоны и приложение можно было использовать на хостинге без доступа к интернету, замените внешние @import шрифтов Google Fonts на системные шрифты или локально размещённые файлы.
- Файл, скачанный кнопкой «Скачать сайт», является самостоятельной страницей с встроенными CSS-стилями.
